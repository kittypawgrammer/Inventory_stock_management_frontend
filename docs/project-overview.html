6 Key Patterns

Architectural patterns and conventions used throughout the codebase.

Lazy Loading

Every feature module (Dashboard, Products, Categories, Suppliers) is lazy-loaded via loadChildren in the router config. Only the shell layout loads eagerly.

Service Inheritance

All domain services extend ApiService, which provides http and buildUrl(). Each subclass defines its own endpoint and HTTP methods.

Container / Presentation

Feature modules use a parent container component that fetches data and passes it to child list/form components via @Input() bindings.

Optimistic Updates

After a successful delete, the local array is filtered immediately without re-fetching. The UI updates before the next navigation cycle.

Reactive Forms

All add/edit forms use ReactiveFormsModule with FormGroup, FormControl, and built-in validators (required, min, Validators.email).

Fetch-on-Navigate

No centralized state store. Each component fetches fresh data from the API on every navigation via ngOnInit(). State lives in component properties only.

Guard-Based Auth

Route protection via a functional CanActivateFn guard that checks AuthService.isLoggedIn(). Unauthenticated users redirect to /login.

Global Search

The topbar component queries all three entity services, filters across types, and navigates to the relevant list with ?search= query params.

7 Backend Context

The frontend consumes a REST API served by a FastAPI backend with PostgreSQL. Here's how they connect.

Backend Stack

A Python FastAPI application using SQLAlchemy ORM for database access, Alembic for migrations, and Pydantic for request/response validation.

8 Backend Behaviors Visible in Frontend

Key backend logic that shapes what the frontend displays and how it behaves.

✓

Soft Deletes

DELETE /products/:id sets is_active = false — products are never physically removed. The frontend only receives active products.

⚙

Computed Stock Status

Stock status (In Stock / Low Stock / Out of Stock) is calculated server-side based on quantity_in_stock vs reorder_level — not stored in the database.

✗

Referential Integrity Guards

Deleting a Category or Supplier is blocked by the backend if products are still linked to it — the frontend receives a 409 error.

⇄

Stock Adjustment Endpoint

PATCH /products/:id/stock accepts a signed change integer and reason — allows incrementing/decrementing stock without full product update.
